# Student Productivity Management System 📚

A comprehensive Java-based application designed to help students manage their academic workload, organize tasks, track progress, and maximize productivity.

## Overview

The **Student Productivity Management System** (also known as SmartStudyPlanner) is a desktop application built with Java that provides students with essential tools to:

- 📝 **Task Management**: Create, organize, and prioritize academic tasks and assignments
- 📅 **Schedule Planning**: Plan study sessions and manage deadlines effectively
- ✅ **Progress Tracking**: Monitor completion of tasks and assignments
- 📊 **Productivity Analytics**: Gain insights into your study patterns and productivity trends
- 🎯 **Goal Setting**: Set academic goals and track progress towards them

## Features

- **Intuitive User Interface**: Easy-to-use desktop application for managing academic tasks
- **Task Organization**: Categorize tasks by subject, priority, and deadline
- **Reminder System**: Get notified about upcoming assignments and deadlines
- **Data Persistence**: Automatic saving of your tasks and progress
- **Productivity Insights**: Visual representations of your study habits and productivity

## Tech Stack

- **Language**: Java
- **Architecture**: Desktop Application
- **Build System**: IntelliJ IDEA Project (SmartStudyPlanner.iml)

## Getting Started

### Prerequisites

- Java Development Kit (JDK) 8 or higher
- IntelliJ IDEA or any Java IDE

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Chaudhary-Hanan/Student_Productivity_Management_System.git
   cd Student_Productivity_Management_System
   ```

2. **Open in IntelliJ IDEA**
   - Open IntelliJ IDEA
   - Select "Open" and navigate to the project directory
   - IntelliJ will automatically recognize the `.iml` file and load the project

3. **Build the project**
   - Use IntelliJ's built-in build tools (Build → Build Project)

4. **Run the application**
   - Locate the main class in `src/`
   - Right-click and select "Run"

## Usage

Once the application is running:

1. **Create New Tasks**: Add tasks with titles, descriptions, and deadlines
2. **Organize**: Categorize tasks by subject or priority level
3. **Track Progress**: Mark tasks as complete and monitor your progress
4. **Review Insights**: Check your productivity statistics and study patterns

## Data Management

Your tasks and progress data are stored in the `data/` directory. The application automatically saves your information, so your data persists between sessions.
